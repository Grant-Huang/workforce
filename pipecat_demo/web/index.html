  • 停止说话 → 转写—
  • 转写 → 回合结束（防抖）—
  • 回合结束 → LLM 首字—
  • LLM 首字 → TTS 首音—
  • TTS 首音 → 开始播放—
  • 总计（可感知延迟）—

端到端那条链路只能测到「转写到达」之后的部分，静音判定到转写之间发生在模型内部， 客户端测不到；这条链路每一段都在本地，所以每段都有数。「防抖」那一段是故意等的 （默认 0.5 秒，留给用户接着往下说），不是模型慢，所以单列出来。
