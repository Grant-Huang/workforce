测试步骤

  1. 在 Mac 上配置仓库根目录 .env（LiveKit Cloud 凭证 + LOCAL_* 模型）
  2. 终端 1：python pipecat_agent.py --room <房间名>
  3. 终端 2：python server.py（本页面，默认 8767）
  4. 点击「连接并开始」，等待 Agent 加入同一 LiveKit 房间

LiveKit 必须直连 wss://*.livekit.cloud，不要经 Cloudflare 代理。 本页面可通过 Tunnel 发布，但 WebRTC 信令仍走 LiveKit Cloud。
