# Archived scripts

`start-livekit.sh` used to launch a local `livekit-server --dev` (port 7880 / `devkey`).

**Current architecture requires [LiveKit Cloud](https://cloud.livekit.io/).**
Browsers and Mac agents connect outbound to `wss://*.livekit.cloud`.
Do not run a local SFU for the supported demos.

Kept here only for historical reference / emergency offline debugging.
